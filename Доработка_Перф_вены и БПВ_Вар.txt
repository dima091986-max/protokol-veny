Вопрос 1. Выносятся ли перфоранты в описание?
Частично — есть баг при 2+ перфорантах.
В функции generateLimbReport() на строках 2439–2451 реализована логика:
javascript
Copy
if (data.perforators.length === 1) {  
    // Полный текст: локализация, диаметр, рефлюкс, тип, значимость, примечание  
    parts.push(`- ${perfText}.`);  
} else {  
    // При 2+ перфорантах — выводится ТОЛЬКО счётчик без деталей:  
    parts.push(`- ${data.perforators.length} недостаточных перфоранта.`);  
}  
То есть:
* 1 перфорант → всё выводится корректно: «Недостаточный перфорант Коккетта (диаметр 4.2 мм, рефлюкс 1.3 сек, escape point, клинически значим)»
* 2 и более → выводится только «2 недостаточных перфоранта.» — теряются локализация, диаметры, рефлюкс, тип и значимость каждого
Что нужно исправить разработчику:
Заменить блок else на перебор каждого перфоранта по той же логике, что для одиночного:
javascript
Copy
} else {  
    data.perforators.forEach(p => {  
        let perfText = `Недостаточный перфорант ${getPerforatorName(p.location)}`;  
        if (p.diameter) perfText += ` (${p.diameter} мм`;  
        if (p.reflux)   perfText += `, рефлюкс ${p.reflux} сек`;  
        if (p.diameter || p.reflux) perfText += ')';  
        if (p.type === 'escape') perfText += ', escape point';  
        if (p.significance === 'significant') perfText += ', клинически значим';  
        if (p.note) perfText += ` (${p.note})`;  
        parts.push(`- ${perfText}.`);  
    });  
}  

Вопрос 2. Поле «Ствол БПВ варикозно изменён?» в форме
Поле отсутствует полностью — ни в форме, ни в выводе протокола.
В текущей форме для БПВ есть только:
* Численные поля диаметров ствола (на бедре / на голени)
* Рефлюкс по стволу с локализацией
Поля «Варикозно изменена — Да/Нет» с выбором локализации нет вообще.
Вместо этого код пытается косвенно вывести расширение через числовые пороги (строки 2262–2282):
javascript
Copy
const thighExpanded = data.bpv.thigh_max && data.bpv.thigh_max >= 5;  
const calfExpanded  = data.bpv.calf_max  && data.bpv.calf_max  > 4;  
  
if (thighExpanded && calfExpanded)  
    → «БПВ расширена: на бедре X мм, на голени X мм»  
else if (thighExpanded)  
    → «БПВ: на бедре расширена до X мм, на голени X мм»  
...  
Проблемы этого подхода:
1. Используется слово «расширена», а не «варикозно изменена» — разные клинические понятия
2. Вариант «варикозно изменена на всём протяжении» — не предусмотрен ни в форме, ни в выводе
3. Если врач не ввёл диаметры, но ствол варикозно изменён — поле никак не зафиксировать
4. Никакой строки о варикозной трансформации ствола БПВ в протоколе не появится вообще

Что нужно добавить разработчику:
В форму блока «1. БОЛЬШАЯ ПОДКОЖНАЯ ВЕНА (БПВ)» — после поля диаметров, до поля рефлюкса — добавить:
Ствол БПВ варикозно изменён?  
    ☐ Нет     ☐ Да →  ☐ На бедре   ☐ На голени   ☐ На всём протяжении  
Технически:
1. Добавить radio bpv_trunk_varicose = none / yes
2. При yes — показывать чекбоксы bpv_trunk_varicose_location: thigh / calf / entire
3. Собирать в data.bpv.trunk_varicose и data.bpv.trunk_varicose_location[]
4. В generateLimbReport() — выводить в протокол:
o none → ничего (или «ствол без варикозной трансформации», если нужно)
o yes + entire → «Ствол БПВ варикозно изменён на всём протяжении»
o yes + thigh/calf → «Ствол БПВ варикозно изменён: на бедре / на голени»
