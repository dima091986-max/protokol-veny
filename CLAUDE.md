# Инструкции для Claude Code — проект «Протокол-Вены»

## Язык
Всегда отвечай на русском языке, независимо от языка команд или комментариев в коде.

## Контекст проекта
Это учебно-исследовательский проект в области медицинской диагностики (не медицинское изделие, не для клинического применения без соответствующей сертификации). При создании документации, интерфейсов или отчётов указывай это явно, если результат может быть воспринят как готовый клинический инструмент.

## Стиль работы
- Пиши модульный, читаемый код — разделяй логику на независимые компоненты, а не один большой файл.
- Перед крупными изменениями кратко объясняй план действий.
- Если задача неоднозначна — переспрашивай, а не додумывай молча.
- Комментарии в коде — на русском, если не указано иное.

## Документация
- Технические описания и пояснения — на русском.
- При оформлении списков литературы — использовать белорусский академический стиль библиографии (ГОСТ/БГМУ), если не указано иное.

## Кодировка файлов
Все текстовые, markdown и html файлы всегда сохраняй в кодировке UTF-8 без BOM. Перед коммитом проверяй, что кириллица в файлах не искажена.
